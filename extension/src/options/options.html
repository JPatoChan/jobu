Saved passwords

Many job sites (Workday, iCIMS, Taleo) make you create an account to apply. On those pages, the Jobu panel makes a strong password, fills it in and saves it here, one per site, and fills it in again when you sign in. Passwords are encrypted with a passphrase you choose and never leave this computer. They lock when you close the browser.

Use at least 8 characters. Jobu can't recover your saved passwords if you forget it.

Settings

Shortcuts: Alt+Shift+F autofills the page, Alt+Shift+N goes to the next page, Alt+Shift+J opens the Jobu panel, Alt+Shift+E goes to the next field Jobu left empty. Submit has no default key. Set one, or change the others, at chrome://extensions/shortcuts.

Claude Code optional

Jobu works without AI. If you use Claude Code on this computer, you can connect it to get rewrite options from Claude on the tailor page. Nothing else in Jobu uses Claude, and it stays off until you connect it.

Checking for Claude Code…

Needs Claude Code on macOS or Linux. To turn it off again, run sh scripts/connect-claude.sh --remove.

Backup and your other devices

To use Jobu on your phone or in another browser, export here and import the file there. It has your profile, saved answers, settings, resume, cover letter and tracked jobs. Saved passwords aren’t included.
